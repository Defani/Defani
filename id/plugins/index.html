Plugin

English · Bahasa Indonesia

Plugin yang saya buat untuk GeoLibre (buatan Qiusheng Wu, opengeos/GeoLibre, DOI Wu & Hofbauer (2026)) dan QGIS (QGIS Development Team, qgis/QGIS). Platformnya milik pembuatnya; pluginnya buatan saya.

Cara kerjanya bersama¶

Statistik pengguna¶

Data diambil langsung dari registri plugin GeoLibre setiap kali halaman ini dibuka.

Plugin GeoLibre¶

Coba langsung di sini: GeoLibre berjalan di dalam halaman ini.

Layout Composer¶

Perancang tata letak kartografi untuk GeoLibre: peta siap cetak dengan layer, grid, inset, legenda, dan ekspor.

Halaman resmi · README lengkap · Repositori · Baca panduan

GBIF Data¶

Mengambil data kejadian (occurrence) dari GBIF langsung ke peta GeoLibre.

Halaman resmi · README lengkap · Repositori · Baca panduan

iNaturalist Extractor¶

Mengambil observasi iNaturalist dan menambahkannya ke peta sebagai layer GeoJSON.

Halaman resmi · README lengkap · Repositori

Terrio Toolbox¶

Panel geoprocessing ala ArcGIS Pro untuk GeoLibre, menempel di kanan seperti ArcToolbox: 36 tool raster dan vektor (Clip, Buffer, Slope, Viewshed, Reclassify, Zonal Statistics, Raster To ASCII, dan lainnya) serta Raster Calculator dengan Con, SetNull, dan Float. Semuanya berjalan di browser dengan terrio-js WebAssembly.

Tutorial dengan tangkapan layar · Repositori · Unduh

Tentang GeoLibre¶

GeoLibre bukan buatan saya. GeoLibre dibuat dan dikelola oleh Qiusheng Wu (ORCID 0000-0001-5437-4073), University of Tennessee, Knoxville, di bawah organisasi opengeos, dan dirilis dengan Lisensi MIT. Saya berkontribusi lewat plugin untuk ekosistemnya (plugin di halaman ini).

GeoLibre adalah GIS cloud-native gratis yang berjalan di browser, desktop, ponsel, dan notebook Jupyter, dengan 1.000+ alat geoprocessing yang berjalan di WebAssembly. Dibangun dengan Tauri, React, TypeScript, MapLibre GL JS, DuckDB-WASM, dan deck.gl.
